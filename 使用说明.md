# 语音增强系统 — 答辩演示操作手册

## 环境准备

```bash
source venv312/Scripts/activate
```

---

## 一、4 种方法对同一音频降噪

测试文件 `data/timit_mixed/SI1005_snr0.wav`

```bash
# Transformer（本项目）
python scripts/infer_transformer.py \
    --checkpoint checkpoints/transformer_stft_improved.pt \
    --input_wav data/timit_mixed/SI1005_snr0.wav \
    --output_wav demo_transformer.wav

# noisereduce（传统谱减法）
python scripts/run_noisereduce_single.py \
    --input_wav data/timit_mixed/SI1005_snr0.wav \
    --output_wav demo_noisereduce.wav

# RNNoise（DSP + GRU）
python scripts/run_rnnoise_demo.py \
    --input_glob "data/timit_mixed/SI1005_snr0.wav" \
    --output_dir outputs/rnnoise_demo

# GTCRN（轻量 ONNX）
python scripts/run_gtcrn_single.py \
    --input_wav data/timit_mixed/SI1005_snr0.wav \
    --output_wav demo_gtcrn.wav
```

生成文件：

| 方法 | 输出 |
|------|------|
| Transformer | `demo_transformer.wav` |
| noisereduce | `demo_noisereduce.wav` |
| RNNoise | `outputs/rnnoise_demo/SI1005_snr0_rnnoise.wav` |
| GTCRN | `demo_gtcrn.wav` |
