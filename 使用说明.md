# 融入卷积频率前端的 Transformer 语音增强

## 环境准备

```bash
# 激活 GPU 虚拟环境 (Python 3.12, PyTorch CUDA)
source venv312/Scripts/activate

# 若 GPU 不可用，CPU 也能跑（代码自动检测）
```

## 答辩演示

### 单条语音降噪（15 秒出结果）

```bash
python scripts/infer_transformer.py \
    --checkpoint checkpoints/transformer_stft_improved.pt \
    --input_wav data/timit_mixed/SI1005_snr0.wav \
    --output_wav demo_enhanced.wav
```

输入 `demo_enhanced.wav` 即为降噪后的干净语音。对比原始含噪 `data/timit_mixed/SI1005_snr0.wav` 听效果。

---

## 模型训练

### 基线模型（标准 L1 Loss）

```bash
python scripts/train_transformer.py \
    --data_dir data/timit_mixed --epochs 30 --batch_size 4 \
    --feature_type stft_log_mag \
    --checkpoint checkpoints/transformer_baseline.pt \
    --history_csv outputs/metrics/baseline.csv
```

### 改进版（频域加权 + 余弦退火）

```bash
python scripts/train_transformer.py \
    --data_dir data/timit_mixed --epochs 30 --batch_size 4 \
    --feature_type stft_log_mag \
    --checkpoint checkpoints/transformer_improved.pt \
    --history_csv outputs/metrics/improved.csv
```

频域加权 L1 和余弦退火已在代码中内置，无需额外参数。

### 断点续训

```bash
python scripts/train_transformer.py ... --resume
```

---

## 批量推理

```bash
python scripts/batch_inference.py
```

对所有 checkpoint 在所有 100 条测试音频上跑推理。输出目录：`outputs/transformer/<模型名>/`

---

## 评估指标

```bash
python scripts/evaluate_metrics.py \
    --metadata_csv data/timit_mixed/metadata_test.csv \
    --enhanced_dir outputs/transformer/STFT_improved \
    --output_csv outputs/metrics/STFT_improved.csv \
    --pair_mode "{noisy_stem}_enhanced.wav"
```

输出每个样本的 STOI 和 SDR，以及平均值。

## 最终结果

| 方法 | STOI | SDR (dB) |
|------|------|------|
| 含噪不处理 | 0.768 | +2.60 |
| RNNoise | 0.695 | +2.69 |
| GTCRN | 0.750 | +3.70 |
| noisereduce | 0.783 | +5.89 |
| Transformer 基线 | 0.807 | +8.55 |
| **Transformer 改进版** | **0.884** | **+12.67** |
